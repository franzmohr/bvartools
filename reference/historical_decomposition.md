# Historical Decomposition

Decomposes the path of a variable over the estimation sample into the
contributions of the identified structural shocks.

## Usage

``` r
historical_decomposition(x, ...)
```

## Arguments

- x:

  an object of class 'bvarmodel' with posterior draws.

- ...:

  further arguments passed to or from other methods.

## Value

See the method,
[`historical_decomposition.bvarmodel`](https://franzmohr.github.io/bvartools/reference/historical_decomposition.bvarmodel.md).
