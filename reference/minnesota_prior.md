# Minnesota Prior

Calculates the Minnesota prior for a model.

## Usage

``` r
minnesota_prior(object, ...)
```

## Arguments

- object:

  an object of a class, for which a method should be called.

- ...:

  arguments passed forward to method.

## Value

The value returned by the method for the class of `object`, as described
on the pages of the methods.

## Details

A generic function used to generate data matrices based on the Minnesota
prior. The function invokes particular methods which depend on the class
of the first argument.
