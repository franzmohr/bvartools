# Minnesota Prior

Forwards the elements of an object of class 'modellist' forward to its
respective method.

## Usage

``` r
# S3 method for class 'modellist'
minnesota_prior(object, ...)
```

## Arguments

- object:

  a list of class 'modellist'.

- ...:

  further arguments passed to or from other methods.

## Value

A list of class 'modellist'.
