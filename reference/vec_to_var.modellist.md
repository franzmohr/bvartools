# Transform a VEC Model to a VAR in Levels

The elements of an object of class `'modellist'` are transformed into
their VAR representation in levels.

## Usage

``` r
# S3 method for class 'modellist'
vec_to_var(object, ...)
```

## Arguments

- object:

  an object of class `'modellist'`.

- ...:

  arguments passed forward to method.

## Value

An object of class `'modellist'`.
